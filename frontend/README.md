# Frontend - Dev Display

Aplicação Web desenvolvida com **React 18** e **Vite**.

## Scripts Disponíveis

Dentro da pasta `frontend` (ou através do workspace com `pnpm --filter frontend <comando>`):

### `pnpm run dev`
Inicia a aplicação em modo de desenvolvimento na porta `3000`.<br />
Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

### `pnpm run build`
Compila a aplicação para produção gerando os arquivos otimizados na pasta `dist/`.

### `pnpm run preview`
Permite visualizar localmente o resultado da build de produção gerada.
